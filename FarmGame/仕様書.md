# 放置系農業ゲーム 仕様書（v0.1 / 1ファイル版 / GPTCODEX投入用）

## 1. 概要
- **タイトル（仮）**：もふねこファーム（仮）
- **ジャンル**：放置系・農業（スマホブラウザ中心）
- **目的**：個人＋友人で「末永く、気軽に」遊べる放置農業ゲーム
- **マネタイズ**：不要（広告/課金なし）
- **オンライン要件**：同期なし（端末ローカルセーブ）
- **プレイ想定**：1日 **3回**、各 **1〜3分**
- **世界観**：ゆる日常 / 現実寄り（野菜・果物） / もふもふ猫の助手

## 2. 主要決定事項（確定）
### 2.1 放置（時間進行）
- **方式**：オフライン差分進行（起動時にまとめて進める）
- **上限**：最大 **8時間**
- **報酬**：**全額**（減衰なし）
- **失敗要素**：なし（枯れる/虫/品質低下なし）

### 2.2 自動化（助手キャラ）
- 助手は **猫**（役割で分離）
- **役割**：収穫担当 / 販売担当
- 猫の稼働には **燃料（カリカリ）**が必要
- 燃料は **コインで購入**
- 燃料が **0** なら該当猫は停止

### 2.3 畑・倉庫
- 畑は **固定グリッド**（拡張あり）
- 倉庫は **無限**

### 2.4 まとめ植え
- 「空きマス全てに同一作物を植える」機能あり（必須）

### 2.5 セーブ移行
- **エクスポート/インポート**あり（JSON）

## 5. ゲームルール仕様

## 5.1 畑（Grid）
- 初期サイズ：**4×3（12マス）**
- 拡張上限（MVP目安）：**6×5（30マス）**
- タイル状態：
  - `empty`
  - `growing`
  - `ready`
- 成長判定：`readyAt <= now` で `ready`

---

## 5.2 作物（Crops）※データ駆動
### 5.2.1 作物一覧（初期バランス案：調整前提）
| cropId | 名前 | 成長(秒) | 売値/個 | 種コスト/個 | 解放条件 |
|---|---|---:|---:|---:|---|
| carrot | にんじん | 8秒 | 6 | 2 | 初期 |
| strawberry | いちご | 15秒 | 18 | 6 | 初期 |
| potato | じゃがいも | 30秒 | 40 | 14 | 畑拡張1回 |
| tomato | トマト | 60秒 | 90 | 32 | 畑拡張2回 |
| pumpkin | かぼちゃ | 120秒 | 210 | 78 | 畑拡張3回 |
| grape | ぶどう | 240秒 | 520 | 200 | 畑拡張4回 |

**意図**
- 「短/中/長」の3帯を作り、1日3回プレイでも回る
- 後半ほど強いが、燃料消費があるため “放置しっぱなし最適” だけになりにくい

---

### 5.2.2 成長段階（sprout/mid/ready）
- 成長表示は 3段階：`sprout` → `mid` → `ready`
- 総育成時間を `T` とする
- 期間配分は原則 3等分
- `T` が3で割り切れない場合、端数は **sprout を短縮**して吸収し、短縮分は **ready に加算**して総和 `T` を維持する
  - 目的：起動直後の変化を早くして体感を良くする（sprout ≤ mid ≤ ready）

---

## 5.3 倉庫（Warehouse）
- 無限容量
- 収穫物は倉庫に加算（作物別に個数管理）

---

## 5.4 猫の助手（Cats）と燃料（Fuel）
### 5.4.1 共通
- 燃料名：**カリカリ**
- 燃料が 0 の間は停止（UIで明示）
- 猫は「時間」ではなく「アクション」で燃料消費（差分計算が簡単＆納得感）

### 5.4.2 収穫猫（Harvester）
- 対象：`ready` タイル
- 動作：収穫 → タイルを `empty` に → 倉庫に +1
- 速度（Lv1）：**1収穫 / 10秒（オンライン稼働時）**
- オフライン時：差分時間内で可能な収穫回数を計算
- 燃料消費：**1収穫 = 1燃料**
- 優先：`readyAt` が古い順（安定）

### 5.4.3 販売猫（Seller）
- 対象：倉庫内の在庫
- 動作：販売 → コイン増加 → 倉庫減少
- 速度（Lv1）：**1アクションで最大10個販売**
- 燃料消費：**10個販売 = 1燃料**（端数は切り上げ）
- 販売優先：売値が高い順（または在庫が多い順）  
  - MVPは **売値高い順** 推奨（分かりやすい）

### 5.4.4 燃料購入（ショップ）
- パック（初期案）
  - Small：50燃料 / 100コイン
  - Medium：200燃料 / 360コイン（少しお得）
  - Large：500燃料 / 800コイン（さらにお得）
- 最大所持（UI都合）：9999 まで（実質無限）

## 6. オフライン差分進行（最大8h）仕様
### 6.1 基本
- 保存：`lastSeen`（epoch ms）
- 起動時：
  - `elapsedMs = now - lastSeen`
  - `if elapsedMs < 0 => elapsedMs = 0`
  - `elapsedMs = min(elapsedMs, 8h)`
- 進行は **分単位ステップ（1分）** を推奨（最大480ループで軽い）

### 6.2 差分進行の処理順（1分ごと）
1) **作物の成長更新**
   - `readyAt <= stepNow` のタイルを `ready` に
2) **収穫猫**
   - 燃料がある限り、`ready` を収穫（ただし“1分あたり上限”を設ける）
3) **販売猫**
   - 燃料がある限り、倉庫から販売（同様に上限）

### 6.3 上限（1分あたり処理量）※暴走防止
- 収穫猫：最大 `ceil(60 / harvestIntervalSec)` 回/分
- 販売猫：最大 6アクション/分（＝Lv1なら最大60個/分）  
  ※MVPでは固定でOK

### 6.4 起動時まとめ表示（Offline Summary）
- 表示内容（最低限）
  - 「おかえり！」
  - 「オフライン：X時間Y分」
  - 「収穫：+N個」
  - 「販売：+Zコイン」
  - 「燃料消費：-F」
- ボタン：「OK」

### 13.1 参照アルゴリズム（成長段階判定）

- 実装は以下の参照アルゴリズムに準拠すること（仕様の解釈ブレ防止）
- `T = growMs`（総育成時間ms）
- 成長表示は 3段階：`sprout` → `mid` → `ready`
- 期間配分は原則3等分。`T` が3で割り切れない場合、端数は **sprout を短縮**して吸収し、短縮分は **ready に加算**して総和 `T` を維持する（sprout ≤ mid ≤ ready）

```ts
export type GrowthStage = "sprout" | "mid" | "ready";

export type StageDurations = {
  sprout: number; // ms
  mid: number;    // ms
  ready: number;  // ms（ready到達までの最後の区間）
};

/**
 * 総育成時間T(growMs)を3段階に分割する。
 * - 原則3等分
 * - 割り切れない端数(0..2ms)はsproutを短くして吸収
 * - 短くした分をreadyへ加算し、合計Tを維持（sprout <= mid <= ready）
 */
export function splitGrowthTimeMs(T: number): StageDurations {
  const t = Math.max(0, Math.floor(T)); // ms整数に丸め
  const base = Math.floor(t / 3);
  const rem = t - base * 3; // 0..2

  const sprout = Math.max(0, base - rem);
  const mid = base;
  const ready = base + rem;

  return { sprout, mid, ready }; // sprout+mid+ready === t
}

/**
 * 経過時間elapsedMsから現在の成長段階を返す。
 * - elapsedMsは0..Tにクランプして判定
 * - readyは「収穫可能（= elapsedMs >= T）」を意味する
 */
export function getGrowthStage(elapsedMs: number, growMs: number): GrowthStage {
  const T = Math.max(0, Math.floor(growMs));
  if (T === 0) return "ready";

  const e = Math.max(0, Math.min(Math.floor(elapsedMs), T));
  const { sprout, mid } = splitGrowthTimeMs(T);

  if (e < sprout) return "sprout";
  if (e < sprout + mid) return "mid";
  return "ready";
}

/**
 * 表示・デバッグ用：段階内経過や残りも欲しい場合に使う。
 */
export function getGrowthState(elapsedMs: number, growMs: number) {
  const T = Math.max(0, Math.floor(growMs));
  const eRaw = Math.max(0, Math.floor(elapsedMs));
  const e = Math.min(eRaw, T);

  const { sprout, mid, ready } = splitGrowthTimeMs(T);
  const t0 = sprout;
  const t1 = sprout + mid;
  const t2 = sprout + mid + ready; // == T

  const progress01 = t2 <= 0 ? 1 : e / t2;

  if (e < t0) {
    return {
      stage: "sprout" as const,
      stageIndex: 0 as const,
      elapsedMs: e,
      remainingTotalMs: Math.max(0, t2 - eRaw),
      stageElapsedMs: e,
      stageRemainingMs: t0 - e,
      progress01,
    };
  }

  if (e < t1) {
    return {
      stage: "mid" as const,
      stageIndex: 1 as const,
      elapsedMs: e,
      remainingTotalMs: Math.max(0, t2 - eRaw),
      stageElapsedMs: e - t0,
      stageRemainingMs: t1 - e,
      progress01,
    };
  }

  return {
    stage: "ready" as const,
    stageIndex: 2 as const,
    elapsedMs: e,
    remainingTotalMs: Math.max(0, t2 - eRaw),
    stageElapsedMs: e - t1,
    stageRemainingMs: Math.max(0, t2 - e),
    progress01,
  };
}

```
